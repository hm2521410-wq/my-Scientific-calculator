# fx-375ES web — スマホ向け関数電卓

カシオ **fx-375ES A** をベースにした、ブラウザで動く関数電卓です。
インストール不要で使えて、Chrome の「ホーム画面に追加」でアプリのように起動できます（PWA）。

3 つの追加機能を載せています。

- **方程式の解法** — 1 次・2 次は厳密解（√ や複素数のまま）、それ以外は実数解を数値探索
- **記号積分** — 原始関数を数式のまま返す（不定積分／定積分）。閉じた式が無ければ数値積分に自動で切り替え
- **複素数計算** — CMPLX モード、`a+bⅈ` と `r∠θ` の相互切り替え

`.github/workflows/pages.yml` を同梱しているので、以後は push するたびに自動で公開されます。
公開先は `https://hm2521410-wq.github.io/my-Scientific-calculator/` です。

> Pages の有効化そのものは Actions のトークンでは実行できません

1. Chrome（Android）で公開 URL を開く
2. メニュー（⋮）▸ **アプリをインストール** / **ホーム画面に追加**

## フリック入力

これが本機との一番大きな違いです。**SHIFT / ALPHA を押さなくても、キーを押したまま指を滑らせるだけで裏の機能が出せます。**

| 方向 | 対応する刻印 | 色 |
|---|---|---|
| タップ | 白（主機能） | — |
| ↑ フリック | SHIFT 機能 | 黄 |
| → フリック | ALPHA 機能 | 赤 |
| ↓ フリック | BASE-N や関連機能 | 青／緑 |
| ← フリック | さらに関連する機能 | 緑 |
| 長押し | 一覧メニュー（右下に ◢ が付くキーのみ） | — |
| 長押し＋なぞり | `SI` キーのみ。指を離さず上下で接頭辞を選択 | — |

押した瞬間に候補が指の周りに出るので、見ながら方向を決められます。
キー上の小さな文字は、その方向に何が入っているかの目印です。

たとえば `sin` キーは、タップで `sin`、↑ で `sin⁻¹`、→ で変数 `D`、↓ で `sinh`、← で `sinh⁻¹`。
`hyp` キーをほとんど使わずに双曲線関数へ直行できます。

**SHIFT / ALPHA キーも残してあります**（左上、小さめ）。押してからキーをタップすると
それぞれ ↑ / → の機能が入ります。従来どおりの操作をしたいときはこちらをどうぞ。

### 実機からキー配置を変えたところ

慣れた位置を崩さないよう、変更は次の 3 点だけに絞っています。

1. **AC を右上へ移動**しました。DEL と隣り合っていて押し間違えるため、
   リプレイキーの右側に離してあります。空いた場所は **DEL が 2 マス分**に広がりました。
2. **リプレイキー（カーソル）を十字配置**にして、大きくしました。
3. **使用頻度の低い 5 つのキーを 1 つに集約**しました（下記）。空いたマスには
   SOLVE / VAR / SI / ⅈ を新設しています。

そのほかのキーは実機と同じ位置のままです。

### 集約したキー（(−) の位置にある 1 キー）

| 操作 | 機能 | 何をするキーか |
|---|---|---|
| タップ | **(−)** | 負の符号。`−5` のように数値の前に付けます。※ このアプリでは通常の `−` キーでも負号として使えるので、実質どちらでも構いません |
| ↑ | **CALC** | 式に変数（A〜F, X, Y, M）を含めて入力しておき、後から値を代入して計算する機能。例：`A+B` と入れて CALC → A と B の値を聞かれ、結果が出ます。値を変えて何度も計算できます |
| → | **A** | 変数 A の入力（実機どおりの位置） |
| ↓ | **ENG** | 結果を工学表記（3 桁ごとの指数）に変換します。例：`1234` → `1.234×10³`。もう一度で `1234×10⁰` のように桁が動きます |
| ← | **M+** | 独立メモリー M に、いまの結果を**足し込み**ます。合計を出しながら計算するときに使います。M の値は `VAR` キーで確認・呼び出しできます |
| 長押し | 一覧 | RCL / STO / M− / ◀ENG / ∠ / ÷R / SOLVE など、残りの機能をメニューで選べます |

- **RCL**（Recall）… 変数に保存した値を式に呼び出します。
- **STO**（Store）… いまの結果を変数 A〜F, X, Y, M に保存します。
- **M−** … 独立メモリーから引きます。
- **÷R** … 割り算の「商と余り」を同時に出します（`17÷5` → 商 3、余り 2）。

## 追加した 3 機能の使い方

### 方程式を解く

式に `=` を入れて `=` キーを押すだけです（`=` 記号は **SOLVE キーの → フリック**）。
**SOLVE キー**（実機の CALC の位置）をタップしても同じことができます。

```
X² − 5X + 6 = 0   →  X₁ = 2 , X₂ = 3
X² − 2 = 0        →  X₁ = −√2 , X₂ = √2      （厳密解）
X² + X + 1 = 0    →  複素数解を 2 つ
cos X = X         →  X = 0.7390851332        （数値解）
ℯ^X = 3X          →  実数解を 2 つとも表示
```

1 次・2 次は係数を見て厳密に解き、3 次以上は有理根を厳密に、残りを数値的に求めます。
多項式でない式は符号変化を走査して**見つかった実数解をすべて**返します
（周期関数のように解が無数にある場合は、初期値に近いものを 8 個まで）。

複数の未知数を含む連立方程式は MODE ▸ EQN から係数を入力してください。

### 記号積分

`∫dx` キーを **↓ フリック**すると、いま入力中の式の原始関数を数式で返します。

```
X²            →  X³/3 + C
1/(X² + 1)    →  tan⁻¹(X) + C
X·ℯ^X         →  ℯ^X·X − ℯ^X + C
sin²X         →  X/2 − sin(2X)/4 + C
(2X+3)/((X+1)(X−2))  →  −ln|X+1|/3 + 7ln|X−2|/3 + C     （部分分数分解）
ℯ^(X²)        →  初等関数では表せません
```

対応している手法は、線形性・置換積分・部分積分（LIATE）・部分分数分解・三角関数の次数下げです。
∫ テンプレートに上端下端を入れてから ↓ フリックすると、原始関数と定積分の値の両方が出ます。
閉じた形が見つからない定積分は、自動で数値積分（適応 Gauss–Kronrod 15 点則）に切り替わります。

`∫dx` を**タップ**したときは本機と同じ数値積分です。`d/dx` キーも同様で、
タップが数値微分、↑ フリックが記号微分になります。

### SI 接頭辞（k, M, m, µ …）

`SI` キー（実機の ENG の位置）は、**答えの表示のしかたを変えるだけ**のキーです。
式には何も入りません。答えが `1000` のときに「キロ」を選ぶと `1 k` と表示されます。

- **長押ししたまま上下になぞる**（推奨）：接頭辞の一覧が画面上に出ます。
  指を置いた位置が「なし」で、**上へなぞると大きい方**（da, h, k, M, G, T, P）、
  **下へなぞると小さい方**（d, c, m, µ, n, p, f）。
  一覧の上部に `1000 → 1 k` のように変換後がリアルタイムで出るので、
  見ながら選んで指を離すと確定します。指は一度も離す必要がありません。
- **フリック**：↑ `k`、→ `M`、↓ `m`、← `µ` をすぐ適用します。
- **タップ**：同じ一覧をパネルで開きます（長押しが使いにくいとき用）。

### 複素数

MODE ▸ CMPLX（または `2` キーの ↑ フリック）。虚数単位 `ⅈ` は **専用キー**（実機の M+ の位置）です。

```
(1 + ⅈ)²   →  2ⅈ
ℯ^(ⅈπ)     →  −1
1 ÷ ⅈ      →  −ⅈ
2∠(π/3)    →  1 + √3 ⅈ        （∠ は ⅈ キーの ↑ フリック）
```

結果表示で `S⇔D` を押すと `a+bⅈ` ⇄ `r∠θ` が切り替わります。
`Abs` / `arg` / `Conjg` は ⅈ キーの ← / ↓ / → フリックです。COMP モードで複素数が出る計算をすると
本機と同じく Math ERROR になります。

## そのほか実装したもの

- **自然表示（Natural-V.P.A.M.）** — 分数・√・累乗・∫・Σ・絶対値を教科書どおりの形で入力／表示。
  カーソルは構造を意識して動き、▲▼ で分子↔分母や上端↔下端を行き来します。式をタップした位置にも移動します。
- **S⇔D** — `√2`, `π/4`, `3/8` のような厳密表示と小数表示の切り替え（帯分数も）
- **モード** — COMP / CMPLX / STAT / BASE-N / EQN / TABLE
- **メモリ** — A–F, X, Y, M 変数、STO / RCL、M+ / M−、Ans / PreAns
- **設定** — Deg / Rad / Gra、Norm1 / Norm2 / Fix / Sci、分数表示、複素数表示、基数
- **関数** — 三角・逆三角・双曲線、log / ln / logₐb / 10ˣ / ℯˣ、√ / ∛ / ˣ√、
  x! / nPr / nCr / GCD / LCM、Pol / Rec、Rnd / Int / Intg / Frac、Ran# / RanInt、
  ENG 変換、DMS（度分秒）、÷R（商と余り）、CONST（物理定数）、CONV（単位換算）
- **計算履歴** — 端末内に保存、HIST から呼び出して再編集
- **PC でも操作可能** — 物理キーボードの数字・演算子・Enter・Backspace に対応

## 取扱説明書に合わせた点

fx-375ES A の取扱説明書（RJA540302-001V01）を参照し、次を実機どおりに揃えました。

- **MODE**：1 COMP／2 CMPLX／3 STAT／4 BASE-N／5 EQN／6 TABLE（MATRIX・VECTOR はこの機種には無し）
- **SETUP**：角度設定（Deg/Rad/Gra）、表示桁数（Fix 0〜9 / Sci 1〜10 / Norm 1・2）、
  分数表示（ab/c・d/c）、複素数表示（a+bⅈ・r∠θ）、BASE-N の基数
- **EQN**：2元／3元連立1次方程式、2次方程式、3次方程式の 4 タイプ
- **STAT**：1-VAR、A+BX、\_+CX²、ln X、e^X、A·B^X、A·X^B、1/X の 8 タイプ
- **TABLE**：f(x) と g(x)、Start / End / Step
- **CONST**：科学定数 40 種（CODATA 2014、説明書のリファレンスシート準拠）
- **CONV**：単位換算コマンド No.01〜40（CONV キーで届く範囲）
- **計算の優先順位**：説明書の 11 段階の表どおり。
  `6÷2(1+2)=1`、`6÷2π=6÷(2π)`、`−2²=−4`、`(−2)²=4` も一致します。

## 既知の制限

- `%` は「100 で割る」の意味に単純化しています（実機の文脈依存の挙動とは異なります）
- EQN / TABLE / STAT の係数・データ入力は電卓キーではなく通常の入力欄です
- 記号積分は初等関数の範囲で、対応する手法は上記のものに限られます
- 未実装：ライン表示入出力の切り替え、循環小数表示（Rdec）、小数点のカンマ表示、
  STAT の FREQ 列と推定値計算、単位換算 No.041〜200、コントラスト調整
