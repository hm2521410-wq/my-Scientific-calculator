# fx-375ES web — スマホ向け関数電卓

カシオ **fx-375ES A** をベースにした、ブラウザで動く関数電卓です。
インストール不要で使えて、Chrome の「ホーム画面に追加」でアプリのように起動できます（PWA）。

3 つの追加機能を載せています。

- **方程式の解法** — 1 次・2 次は厳密解（√ や複素数のまま）、それ以外は実数解を数値探索
- **記号積分** — 原始関数を数式のまま返す（不定積分／定積分）。閉じた式が無ければ数値積分に自動で切り替え
- **複素数計算** — CMPLX モード、`a+bⅈ` と `r∠θ` の相互切り替え

## 使ってみる

```bash
npm start           # http://127.0.0.1:8123 で配信
```

スマホから使う場合は同じ Wi-Fi 内で PC の IP を開くか、GitHub Pages にデプロイしてください
（`.github/workflows/pages.yml` を同梱。リポジトリの Settings ▸ Pages で
Source を **GitHub Actions** にすると、push のたびに自動公開されます）。

### アプリとして入れる

1. Chrome（Android）で公開 URL を開く
2. メニュー ▸ **アプリをインストール** / **ホーム画面に追加**
3. 以後はアイコンから全画面で起動し、**オフラインでも動きます**（Service Worker でキャッシュ）

iOS の Safari は 共有 ▸ 「ホーム画面に追加」で同様に使えます。

> PWA のインストールと Service Worker は `https://` か `localhost` でのみ有効です。
> `file://` で index.html を直接開くと ES モジュールが CORS で止まるため、必ずサーバー経由で開いてください。

## フリック入力

これが本機との一番大きな違いです。**SHIFT / ALPHA を押さなくても、キーを押したまま指を滑らせるだけで裏の機能が出せます。**

| 方向 | 対応する刻印 | 色 |
|---|---|---|
| タップ | 白（主機能） | — |
| ↑ フリック | SHIFT 機能 | 黄 |
| → フリック | ALPHA 機能 | 赤 |
| ↓ フリック | BASE-N や関連機能 | 青／緑 |
| ← フリック | さらに関連する機能 | 緑 |

押した瞬間に候補が指の周りに出るので、見ながら方向を決められます。
キー上の小さな文字は、その方向に何が入っているかの目印です。

たとえば `sin` キーは、タップで `sin`、↑ で `sin⁻¹`、→ で変数 `D`、↓ で `sinh`、← で `sinh⁻¹`。
`hyp` キーをほとんど使わずに双曲線関数へ直行できます。

**SHIFT / ALPHA キーも残してあります**（左上、小さめ）。押してからキーをタップすると
それぞれ ↑ / → の機能が入ります。従来どおりの操作をしたいときはこちらをどうぞ。

## 追加した 3 機能の使い方

### 方程式を解く

式に `=` を入れて `=` キーを押すだけです（`=` 記号は CALC キーの → フリック）。
CALC キーの ↑ フリック（SOLVE）でも同じことができます。

```
X² − 5X + 6 = 0   →  X₁ = 2 , X₂ = 3
X² − 2 = 0        →  X₁ = −√2 , X₂ = √2      （厳密解）
X² + X + 1 = 0    →  複素数解を 2 つ
cos X = X         →  X = 0.7390851332        （数値解）
ℯ^X = 3X          →  実数解を 2 つとも表示
```

1 次・2 次は係数を見て厳密に解き、3 次以上は有理根を厳密に、残りを数値的に求めます。
多項式でない式は符号変化を走査して**見つかった実数解をすべて**返します
（周期関数のように解が無数にある場合は、初期値に近いものを 8 個まで）。

複数の未知数を含む連立方程式は MODE ▸ EQN から係数を入力してください。

### 記号積分

`∫dx` キーを **↓ フリック**すると、いま入力中の式の原始関数を数式で返します。

```
X²            →  X³/3 + C
1/(X² + 1)    →  tan⁻¹(X) + C
X·ℯ^X         →  ℯ^X·X − ℯ^X + C
sin²X         →  X/2 − sin(2X)/4 + C
(2X+3)/((X+1)(X−2))  →  −ln|X+1|/3 + 7ln|X−2|/3 + C     （部分分数分解）
ℯ^(X²)        →  初等関数では表せません
```

対応している手法は、線形性・置換積分・部分積分（LIATE）・部分分数分解・三角関数の次数下げです。
∫ テンプレートに上端下端を入れてから ↓ フリックすると、原始関数と定積分の値の両方が出ます。
閉じた形が見つからない定積分は、自動で数値積分（適応 Gauss–Kronrod 15 点則）に切り替わります。

`∫dx` を**タップ**したときは本機と同じ数値積分です。`d/dx` キーも同様で、
タップが数値微分、↑ フリックが記号微分になります。

### 複素数

MODE ▸ CMPLX（または `2` キーの ↑ フリック）。虚数単位 `ⅈ` は ENG キーの → フリックです。

```
(1 + ⅈ)²   →  2ⅈ
ℯ^(ⅈπ)     →  −1
1 ÷ ⅈ      →  −ⅈ
2∠(π/3)    →  1 + √3 ⅈ        （∠ は (−) キーの ↑ フリック）
```

結果表示で `S⇔D` を押すと `a+bⅈ` ⇄ `r∠θ` が切り替わります。
`Abs` / `arg` / `Conjg` も使えます。COMP モードで複素数が出る計算をすると
本機と同じく Math ERROR になります。

## そのほか実装したもの

- **自然表示（Natural-V.P.A.M.）** — 分数・√・累乗・∫・Σ・絶対値を教科書どおりの形で入力／表示。
  カーソルは構造を意識して動き、▲▼ で分子↔分母や上端↔下端を行き来します。式をタップした位置にも移動します。
- **S⇔D** — `√2`, `π/4`, `3/8` のような厳密表示と小数表示の切り替え（帯分数も）
- **モード** — COMP / CMPLX / STAT / BASE-N / EQN / TABLE
- **メモリ** — A–F, X, Y, M 変数、STO / RCL、M+ / M−、Ans / PreAns
- **設定** — Deg / Rad / Gra、Norm1 / Norm2 / Fix / Sci、基数
- **関数** — 三角・逆三角・双曲線、log / ln / logₐb / 10ˣ / ℯˣ、√ / ∛ / ˣ√、
  x! / nPr / nCr / GCD / LCM、Pol / Rec、Rnd / Int / Intg / Frac、Ran# / RanInt、
  ENG 変換、DMS（度分秒）、÷R（商と余り）、CONST（物理定数）、CONV（単位換算）
- **計算履歴** — 端末内に保存、HIST から呼び出して再編集
- **PC でも操作可能** — 物理キーボードの数字・演算子・Enter・Backspace に対応

## 画像から読み取れなかったところ

写真だけでは確定できず、こちらの判断で決めた点です。**実機と違っていたら教えてください。**

1. **MODE メニューの中身** — 写真には `MODE/SETUP` キーしか写っておらず、番号と機能の対応が読めません。
   fx-991ES 系に合わせて COMP / CMPLX / STAT / BASE-N / EQN / TABLE の 6 つにしました。
   実機に **MATRIX / VECTOR** があるなら未実装です。
2. **SETUP の項目** — 画面に出るメニューなので写真からは不明です。角度単位・表示桁数・基数のみ入れています。
   （Math/Line 入力切替、小数点表示、コントラスト等は未実装）
3. **STAT モードの詳細** — 1 変数統計と 1 次回帰のみ実装しました。
   実機が対応する回帰の種類（対数・指数・累乗・逆数など）や度数入力の有無が分かりません。
4. **CONST / CONV の全リスト** — 実機は各 40 項目ですが、番号と内容の対応表が写真にありません。
   代表的なものを CONST 24 件 / CONV 26 件だけ入れています（CODATA 2018 値）。
5. **√ キーの ALPHA（ピンクの ■）** — 写真では記号がつぶれていて判読できませんでした。
   暫定で `ˣ√` を割り当てています。
6. **`∫dx` キーの黄色い刻印** — `d/dx` と読みましたが、その右の小さな記号が判別できていません。
7. **BASE-N のワード長** — 32 ビット 2 の補数と仮定しました。
8. **キー配列の 1 か所だけ意図的に変更** — 実機の CALC 行は 4 キーですが、
   6 列グリッドが空くのでフリック専用になりがちな `d/dx` と `Σ` を独立キーとして置いています。

## 既知の制限

- `%` は「100 で割る」の意味に単純化しています（実機の文脈依存の挙動とは異なります）
- EQN / TABLE / STAT の係数・データ入力は電卓キーではなく通常の入力欄です
- 記号積分は初等関数の範囲で、対応する手法は上記のものに限られます
